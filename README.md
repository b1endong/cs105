# Crossy Road Clone — CS105

Game **Crossy Road** clone 3D xây dựng bằng React + React Three Fiber, phát triển cho môn học **CS105 - Đồ họa Máy tính**.

Người chơi điều khiển nhân vật vượt qua các làn xe, sông ngòi và chướng ngại vật trên bản đồ vô tận. Hỗ trợ **4 góc nhìn camera** có thể chuyển đổi trong lúc chơi: Isometric, Top-Down, Third-Person, First-Person.

**Tech stack:** React · React Three Fiber · Three.js · Vite

## Cài đặt

```bash
# 1. Clone repo
git clone https://github.com/b1endong/cs105.git
cd cs105

# 2. Cài dependencies
npm install

# 3. Chạy development server
npm run dev
```

Mở trình duyệt tại `http://localhost:5173`
